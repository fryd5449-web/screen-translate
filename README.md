# مترجم الشاشة 1.0.0

أداة خفيفة لـ Windows 10 وWindows 11 تلتقط منطقة يحددها المستخدم، وتتعرف على النص محليًا، ثم تعرض ترجمته العربية.

## الاستخدام

1. شغّل **مترجم الشاشة** من سطح المكتب أو قائمة Start.
2. اضغط الزر العائم، أو استخدم `Ctrl + Shift + T`، ثم حدد النص على الشاشة.
3. تظهر الترجمة العربية في نافذة صغيرة يمكن نسخها أو إعادة التحديد منها.

يدعم التعرف المبدئي على الإنجليزية والفرنسية والألمانية والإسبانية والعربية. يعمل OCR محليًا، بينما تحتاج الترجمة إلى اتصال بالإنترنت.

يمكن إبقاء التطبيق في الخلفية من أيقونة شريط النظام، وإزالته من **التطبيقات المثبتة** في إعدادات Windows أو عبر اختصار إزالة التثبيت في قائمة Start.
